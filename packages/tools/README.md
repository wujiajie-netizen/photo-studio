# 电商业务工具

阶段 3 实现本地模拟图片工具。仅注册经过参数校验的白名单业务工具，每个任务使用独立运行目录。

`prepareProductImage` 完整解码静态 JPG、PNG 或 WebP，限制 20 MB / 1600 万像素，校正方向后输出无原始元数据的 PNG。

`renderMockProductImage` 使用已确认的参数裁去边缘空白、缩放原图并排版到固定背景，返回真实 PNG 字节和尺寸。标准长边 1024，高清长边 2048；任务取消信号在处理前后检查。描述仅用于保存备注，此工具不执行智能抠图或语义重绘。

工具只接收本任务素材字节、参数、图片序号与取消信号；文件读写、结果编号、SQLite 与任务进度由服务层负责。替换真实引擎时保持此边界。
