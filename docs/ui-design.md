# UI 设计与页面还原规范

## 最新创作页（2026-10-07）

保留左侧对话与固定输入、右侧作品场景的独立外壳。右侧多个画板使用真实编辑文档，标题可拖动排布；选择后显示图片或文字浮动操作，工具切换互斥。浮动条需保持在可见操作区，图层属性按需展开，底部保留选择、抓手、文字、画笔、形状、素材、导入和撤销重做；缩放是绝对 3%–300%，适应当前与查看全部分别提供。

文字点击放置、双击编辑，字体和格式即时反馈；图形拖动产生，箭头方向与拖动一致。模板/素材/图片库支持搜索、分类、插入及撤销，只使用自有电商版式与用户图片。裁剪、扩图和涂抹使用独立操作状态，取消保留原文档；图片任务紧凑显示当前进度，并可展开历史。下载设置提供文件名、PNG/JPG 和输出尺寸，结果包含当前编辑。

旧章节中的单作品、相对缩放与完整编辑器跳转为历史布局，当前创作页已由以上结构更新。效果验收与尚未实测的参考交互见 handoff 第 0 节。

## 目标

本项目采用“真实产品页面对标 + 自有品牌表达”的方式建设 PC Web 界面。美图设计室真实页面用于确认信息架构、操作路径、布局比例和状态反馈；产品名称、Logo、宣传文案、专属图标、模板与示例素材不直接复制。

首版以 1440px 宽桌面端为验收基准，优先保证核心电商工作流清晰、连续、可操作，再补充非关键视觉细节。

## 还原方法

界面实现按以下优先级取证：

1. 真实页面与真实交互状态。
2. 同一功能的官方介绍页、帮助文档和公开演示。
3. 已确认的产品流程与本项目业务范围。
4. 无公开依据的缺失状态采用本项目统一设计语言补齐，并标记为自主设计。

不根据单张生成图反推完整产品。生成图片只用于商品示例、场景素材、模板封面和无法直接复用的演示内容。

## 页面地图

### 全局框架

- 工作台外壳：首页、项目和资产使用固定左侧主导航，主内容区承载 Agent、工具入口和内容列表。
- 生成任务外壳：商品套图和商品详情页使用顶部任务栏、左侧任务类型导航、配置栏和右侧预览区。
- 编辑器外壳：编辑器使用独立顶部文件栏、左侧工具栏、属性区和中央画布。
- 全局反馈：三种外壳共享消息提示、确认弹窗、任务进度和错误提示的视觉规则。

工作台主导航包含工作台、AI 商品图、商品套图、商品详情页、项目与资产。进入生成任务或编辑器后，可以切换为更适合连续操作的专用外壳，但必须保留明确的返回入口。

设置是辅助入口，不作为主导航中的高频业务页面。

### MVP 页面

| 页面 | 核心目的 | 首屏关键内容 | 必须采集的状态 |
| --- | --- | --- | --- |
| 工作台首页 | 快速开始任务 | Agent 输入、常用工具、最近项目 | 默认、输入中、提交后、空记录 |
| AI 商品图 | 从商品原图生成可用商品图 | 素材区、场景配置、参数与操作区 | 未上传、已上传、生成中、成功、失败 |
| 商品套图 | 批量生成一组电商图片 | 商品信息、平台与规格、套图结构 | 初始、配置完成、批量生成、部分失败 |
| 商品详情页 | 生成 A+ 或详情模块 | 商品素材、卖点、模块选择、预览 | 初始、模块配置、生成中、组合结果 |
| 项目与资产 | 查找并继续历史工作 | 项目列表、素材分类、筛选入口 | 有数据、空状态、加载、读取失败 |
| 图片编辑器 | 调整并导出生成结果 | 画布、工具区、属性区、图层与导出 | 默认、选中元素、编辑中、保存中 |
| 本地设置 | 检查本机能力 | Codex CLI、本地目录、任务执行状态 | 可用、未登录、不可用、受限 |

## 页面结构

### 工作台首页

首屏由欢迎与任务输入区、常用电商工具、最近项目三部分组成。Agent 输入是主操作，工具入口是并列的确定性入口，最近项目用于继续任务。

页面不能呈现为单纯聊天工具：用户在首屏应能直接识别“制作商品图、制作套图、制作详情页”三个主要任务。

### 已进入的创作对话（2026-10-06）

用户进入历史会话或提交首条需求后，切换为左侧对话、右侧画板的创作布局：隐藏欢迎宣传、工具推荐和最近项目。左侧窄栏按轮次连续展示用户需求、助手回复与方案，输入框固定底部；历史会话通过标题栏按钮展开，不占据独立常驻栏。右侧占主要空间，用于展示本会话真实生成的作品，选择图片、调整预览比例、下载或进入编辑器。方案必须紧跟本轮回复，不能另在页面底部重复罗列所有任务。

该结构依据用户于 2026-10-06 的纠正，以及当天打开已登录的“咖啡豆介绍”创作记录实际核对。参考页左侧有对话与生成图缩略图，右侧为生成图片画板及修改、缩放和下载入口。此观察替代此前仅参考首页而作出的常规聊天布局；图片编辑深度仍以本项目已实现的编辑器能力为准。

输入框固定在对话区底部，消息区独立滚动；Enter 发送、Shift + Enter 换行，中文输入法组合输入不触发发送。查看旧消息时不强制拉回底部，提供最新回复入口。排队、执行、失败、停止和重试直接显示在本轮回复位置。

“自行补充”“你决定”“继续”必须结合已保存的完整会话理解。风格、平台和比例等视觉配置可采用合理默认值；商品规格、功效、成分、产地与认证不能凭空补造。图片可选、同页生成与结果回显是本次流程调整目标，相关业务结构确认后再接入，不能将布局完成记为文字生图功能完成。

### AI 商品图

采用连续任务结构：上传商品、配置场景与规格、执行生成、查看结果。配置和结果可以位于同一页面，也可以分步展示，但用户应始终知道当前步骤、已选素材和主要操作。

生成结果支持单图重试、保存到项目、进入编辑器和导出。首版不展示尚未接入的高级能力入口。

### 商品套图与商品详情页

两页共用商品素材与基础规格的视觉模式，差异部分分别展示套图结构和详情模块。批量结果必须清楚区分成功、执行中和失败的单项，避免只提供一个整体进度。

### 图片编辑器

编辑器以画布为中心，工具和属性围绕当前选中内容显示。MVP 只保留图片、文字、图层、基础变换、撤销重做、保存和导出，不放置不可用的装饰性按钮。

## 视觉原则

- 整体采用轻量、克制的工具型界面，主操作突出，辅助信息弱化。
- 工作流页面优先保证表单、素材和结果之间的层级，不用大面积营销视觉干扰任务。
- 卡片、输入框、按钮、弹窗和状态标签使用统一圆角、边框、阴影和间距体系。
- 正常文本、次要文本、占位文本、禁用文本和错误文本必须有清晰层级。
- 品牌主色和强调色在真实页面采集后建立为设计变量；采集前不写死近似色值。
- 图标优先采用统一图标库，自有品牌标识单独设计。

## 基础组件

MVP 优先建立以下通用组件，不提前扩展完整设计系统：

- 应用侧边栏与顶部栏
- 主按钮、次按钮、文字按钮与危险操作
- 单行输入、多行输入、选择器与分段选择
- 上传区、素材缩略图与结果卡片
- 工具入口卡片与项目卡片
- 步骤提示、状态标签与任务进度
- 空状态、加载状态、错误状态与重试入口
- 抽屉、确认弹窗和消息提示

组件状态至少覆盖默认、悬停、按下、聚焦、禁用和错误。只在真实复用出现后抽取业务组件。

## 页面状态要求

所有核心页面必须明确以下状态，不允许只实现理想成功画面：

- 初始与空状态
- 本地数据加载中
- 用户输入不完整或格式错误
- 任务排队、执行与取消中
- 整体成功、部分成功与失败
- 重试、恢复和结果已保存
- Codex CLI 或本地图片工具不可用

异步任务的状态变化应在当前操作位置附近反馈，同时保留可查看的全局任务状态。

每张参考图记录来源页面、采集日期、浏览器视口、页面状态和用途。原始浏览器截图存放在 `output/playwright/designkit/`，文件按“页面-状态-序号”命名，例如：

```text

```

配套索引使用 `docs/references/designkit/index.md`，索引引用原始截图并区分：

- 可直接观察到的真实状态
- 来自官方介绍或帮助文档的补充状态

登录、付费或其他不可公开访问的状态不绕过权限获取。截图只作为内部设计参考，不直接作为产品素材发布。

## 实现与验收

### 创作页同页操作（2026-10-06）

本次操作区细化：已进入会话时采用独立创作外壳，收起全局侧栏和顶部栏，左侧保留返回工作台、当前标题、历史搜索和新建；画板占据剩余宽度。输入区直接提供图片上传、已有素材引用、当前素材预览和移除，沿用上一轮素材时也必须显示提示。

选中作品后的工具条提供 AI 改图、添加文字、图层与属性、引用图片。基础编辑直接在创作页完成，复用已有编辑文档和自动保存：文字样式、图片与文字的移动缩放旋转、显隐锁定、复制删除、层序、居中对齐、加入会话作品图层、画布尺寸背景与居中裁剪。裁剪保留图层，撤销可恢复。修改与完整编辑器共享文档；下载 PNG 与 AI 改图引用包含当前编辑内容，生成原图不改写。

底部控制包括选择、抓手、文字、图层、撤销重做和操作帮助；作品条包括上一张、下一张、总览、缩放数字输入和适应窗口。H/V 切换工具，方向键切换作品，Ctrl + 滚轮缩放，普通滚轮平移。保存失败应保留内容并阻止切换作品或离开，刷新恢复已保存文档。参考站的原图智能拆层、OCR 文字拆分、画笔/形状、专用超清、无限画板和视频不冒充已实现能力，详见参考索引的逐项对照。

保留左侧当前对话、右侧画板。方案先展示制作内容，再自动补齐执行参数，用户点击「开始生成」后执行。比例、质量、数量与可选素材在方案内按需展开；保存位置默认为当前会话项目，无项目时自动创建。进度、停止、失败和重试留在对应轮次；作品缩略图回到本轮回复，点击联动画板。画板提供抓手平移、相对适应窗口的缩放、复位、下载和编辑。选中结果可「用作下轮素材」，在输入区明确显示图片；用户描述需要修改和保留的内容，再确认新方案。

最新官方指南区分 Agent 对话创作和明确任务的表单工具，建议查看效果后补充修改约束；本项目据此保留确认与多轮反馈，避免把用户友好等同于发送一句话后立即生图。参考 [功能入门](https://www.designkit.cn/help/143) 与 [生成效果调整](https://www.designkit.cn/help/150)。

每个页面按“结构骨架 → 静态视觉 → 交互状态 → 数据接入”的顺序完成。视觉对照在 1440px 宽视口下进行，并同时检查较窄桌面窗口不出现关键操作遮挡。

页面验收关注：

1. 导航、内容区和关键操作的位置与比例。
2. 标题、表单、素材、结果和辅助信息的视觉层级。
3. 间距、字号、圆角、边框、色彩和图标的一致性。
4. 悬停、选中、加载、失败、禁用和弹窗状态。
5. 从入口到结果保存的流程是否连续，用户是否随时知道下一步操作。

实际采集值与本文件冲突时，先更新文档中的视觉基准；产品范围与工作流冲突时停止实现并确认，不以页面外观替代业务决策。
