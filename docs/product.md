# MVP 产品范围

## 产品定位

为电商商家提供从商品素材到可上架视觉内容的本地 AI 工作台。Agent 负责理解、规划、调度和检查；独立工具负责确定性较高的生成与编辑任务。

## 目标用户

- 缺少专业设计人员的中小电商商家
- 需要批量上新和多平台适配的运营人员
- 需要统一品牌视觉和重复复用设计方案的团队

## 页面范围

1. 工作台首页
   - Agent 输入区
   - 常用电商工具
   - 最近项目与任务
2. AI 商品图
   - 素材上传、主体处理、场景配置、生成结果
3. 商品套图
   - 平台、地区、语言、比例、卖点和图片结构配置
4. A+ / 商品详情页
   - 详情模块选择、分模块生成、组合和导出
5. 编辑器
   - 图片、文字、图层、对齐、撤销重做和导出
6. 项目与资产
   - 作图记录、生成记录、商品素材和创作参考
7. 本地设置
   - Codex CLI 状态、本地目录和任务状态

## 核心流程

### Agent

```text
输入目标（素材可选）
→ 识别需求
→ 检查必要参数
→ 缺失信息时追问
→ 生成计划与预计消耗
→ 用户确认
→ 调用本地工具
→ 检查结果
→ 局部重试或完成
→ 保存项目
```

2026-10-06 用户确认创作页采用「对话补全 → 同页方案与参数 → 点击开始生成 → 同页画板结果」。纯文字可以生成视觉示意；有商品原图时沿用素材。视觉配置由助手补齐，可在方案内调整比例、质量与数量，不要求跳转重复填表。项目未指定时自动创建，同会话后续执行默认沿用已有项目。对话内作品缩略图联动画板；选中作品可通过已有素材接口作为下轮原图，再明确修改和保留要求。生成仍需用户确认，不把发送消息视为自动生图。

创作页基础编辑就近完成：新增文字、图片图层、形状、画笔、变换与裁剪、显隐锁定、层序、复制删除、撤销重做，复用同一编辑文档自动保存。下载和下轮引用使用当前编辑画面；生成原图保留。

2026-10-07 用户进一步要求全部非视频创作工具及交互对标，并授权后续字段接入。图片工具提供局部涂抹改图、消除、无痕改字、抠图、超清、扩图、识字编辑与拆层，使用独立任务记录，处理前确认，处理中可停止，失败可重试，成功产生同会话新作品。识字必须识别图片真实文字、重建底图并生成可编辑文字；拆层必须产生独立背景与透明主体。无限多画板和逐项参考实测仍属于完成目标，不能以基础编辑已可用缩小本次验收范围。接入及验证状态见 `creation-tools-contract.md`。

### 商品图

```text
上传商品
→ 主体处理
→ 选择推荐场景、参考图或文字描述
→ 设置比例、数量和质量
→ 生成
→ 重试、编辑、保存或导出
```

### 商品套图与详情页

```text
上传商品素材
→ 设置平台、地区、语言和尺寸
→ 填写商品卖点
→ 选择套图结构或详情模块
→ 批量生成
→ 单图重试与编辑
→ 整套导出
```

## Agent 判定标准

系统必须具备目标理解、参数补全、任务规划、工具选择、结果观察和调整执行能力。仅将用户输入映射到一个固定接口，不视为完整 Agent。

## MVP 不包含

- 移动 App
- 云端部署和多租户 SaaS
- 团队实时协同
- 在线支付、发票和商业授权系统
- AI 模特、试衣、试鞋和完整视频生产
- PPT、Logo、办公设计和泛社媒设计
- 像素级复制第三方商标、品牌素材和受保护模板

## 验收标准

- 1440px PC 页面下主要布局和操作完整可用。
- 首页、商品图、商品套图和详情页流程能够走通。
- 任务包含等待、执行、成功、失败、取消和重试状态。
- 结果可保存到项目，并能进入编辑器继续处理。
- 页面刷新或服务重启后，已持久化任务和项目不丢失。
- Codex CLI 不可用、未登录或额度受限时提供明确错误。
- 模型提供者可替换，页面和业务流程不依赖 CLI 原始事件格式。
