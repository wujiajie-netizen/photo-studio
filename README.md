# Photo Studio

面向电商用户的本地 PC Web AI 视觉生产工作台。产品采用“Agent 入口 + 场景化工具 + 图片编辑器 + 本地资产”的混合形态。

## MVP 核心能力

- Agent 对话、任务规划、参数确认、执行与图片检查
- 商品图上传、裁去空白边缘、白底图和场景图流程
- 商品套图生成流程
- A+ / 商品详情页生成流程
- 生成记录、项目和本地资产
- 基础图片编辑器
- 本地任务状态、失败重试和结果导出

## MVP 运行边界

- 所有应用服务、数据库和文件均在本机运行。
- 大模型通过本机已登录的 Codex CLI 使用，不配置 OpenAI API Key。
- 不使用 Docker。
- Codex CLI 仍需要联网，并受当前账户使用额度限制。
- 真实商品生图通过本机已登录的 Codex CLI 内置图片生成能力执行，不依赖本地扩散模型；生成会消耗 Codex 账户额度。

## 本地启动

使用 Node.js 24 LTS（至少 24.15.0）。在项目根目录执行：

```powershell
.\scripts\start.ps1
```

首次启动会安装锁定的依赖，随后启动前后端。打开 [本地工作台](http://127.0.0.1:5173)。

也可手动执行 `npm ci` 后使用 `npm run dev`。按 `Ctrl+C` 停止；另一个终端可执行 `.\scripts\stop.ps1`。

## 开发检查

```powershell
npm run lint
npm run typecheck
npm run build
npm test
```

运行数据保存在 `data/`，包含 SQLite 数据库、上传、生成、导出和独立任务目录，不提交版本库。已接入 Agent 需求规划、商品图、套图、详情模块及基础编辑器；真实生图统一通过 Codex。

阶段 1 已完成：在 [项目与资产](http://127.0.0.1:5173/projects) 中创建项目，查看详情或重命名；首页展示最近保存的三个项目。项目在页面刷新和服务重启后保留。

首页可提交需求、回答追问并查看结构化创作计划；会话、消息和任务保存在本机，可切换历史会话、取消任务或重试失败需求。[本地设置](http://127.0.0.1:5173/settings) 显示实际 CLI 版本和 ChatGPT 登录状态。未完成任务在服务重启后标记中断，可手动重试。

计划信息完整后，可进入确认页选择素材、项目并核对每一步参数。Agent 调用已确认的工具，使用 Codex 检查真实图片；每步最多自动重试一次，合格图片自动保存项目。失败或取消后可重试未完成步骤，已通过的图片保留。图片生成与检查均消耗 Codex 账户额度，最终上架前仍需核对商品细节。

生成结果可进入编辑器，添加图片和文字，调整位置、大小、旋转、对齐和图层顺序，支持撤销重做、自动保存和 PNG 导出。项目资产页可上传、预览和下载素材；作品编辑数据保存在本机，多个窗口同时修改时会提示版本冲突。

[AI 商品图](http://127.0.0.1:5173/product-image) 支持原图上传、裁去空白边缘、三种背景、四种比例、1–4 张生成和两档质量。Codex 接收原图与描述生成真实 PNG；应用适配确认的输出尺寸，保留整图。可查看历史、取消、重试、保存项目、进入编辑器和下载。高清表示导出长边 2048，原生细节取决于生成结果；请核对商品外观及包装文字。

[商品套图](http://127.0.0.1:5173/product-kit) 和 [详情页](http://127.0.0.1:5173/detail-page) 支持平台、地区、语言、卖点与模块配置，Codex 辅助整理文案；各模块的商品画面同样使用 Codex 生图，确认的文案由本地排版工具绘制。支持单模块重试、整套 ZIP 和详情长图导出。

CLI 需要支持 `--json`、`--output-schema`、`--ignore-user-config`、`--ignore-rules` 和 `app-server --stdio`，使用 `codex login` 登录 ChatGPT。Windows 自动定位 PATH 下官方 npm 安装的原生程序；其他位置可通过 `PHOTO_STUDIO_CODEX_PATH` 指定原生可执行文件。

规划与文案使用 `codex exec`，忽略用户工具配置并采用 CLI 默认模型。生图使用 Codex 应用协议，通过实际 `imageGeneration` 完成事件接收 PNG 字节；不会读取模型回复中的任意文件路径，也不会把“已完成”文字当作图片。生图任务关闭 Shell、插件、应用、MCP、浏览器和子 Agent，在独立任务目录运行，保留 ChatGPT 认证，不继承 API Key。目前生图调度模型采用本机实测可用的 `gpt-5.5`，可通过 `PHOTO_STUDIO_CODEX_IMAGE_MODEL` 指定账户支持的调度模型。

无需安装 Python、OpenVINO 或下载扩散模型。此前已下载的实验模型保留在 `data/runtimes/openvino`，应用不再读取它；当前依赖与启动流程均不包含本地图片引擎安装。

任务拆分、接口和验收记录见 [开发说明](docs/development.md)。
