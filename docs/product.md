# MVP 产品范围

2026-10-07 本地编辑实验版：保持整图生成作为主要创作路径，用户需要编辑时按需识字、抠图或拆层。三个编辑功能试验本地专用工具以减少 Codex 生图调用；完整拆层仍保留一次前景语义分析。用户授权模型安装和 CPU 处理耗时，图层字段、任务交互和结果持久化沿用现有结构。复杂字体、背景补全、透明或遮挡元素的效果需要多类素材验证，不承诺任意图片都能无损还原。

## 产品定位

为电商商家提供从商品素材到可上架视觉内容的本地 AI 工作台。Agent 负责理解、规划、调度和检查；应用工具负责执行图片生成、素材处理、编辑与排版，其中真实生图仍由 Codex 模型完成。

## 目标用户

- 缺少专业设计人员的中小电商商家
- 需要批量上新和多平台适配的运营人员
- 需要统一品牌视觉和重复复用设计方案的团队

## 页面范围

1. 工作台首页
   - Agent 输入区
   - 常用电商工具
   - 最近项目与任务
   - 左侧最近对话入口与覆盖式侧栏，支持搜索、按时间分组、重命名、置顶及多选批量操作；分享暂不可用
   - 删除对话需确认，仅从对话入口移除并禁止继续访问，已保存的项目与作品保留；进行中的任务需先完成或停止
2. AI 商品图
   - 素材上传、主体处理、场景配置、生成结果
3. 商品套图
   - 平台、地区、语言、比例、卖点和图片结构配置
4. A+ / 商品详情页
   - 详情模块选择、分模块生成、组合和导出
5. 编辑器
   - 图片、文字、图层、对齐、撤销重做和导出
6. 项目与资产
   - 作图记录、生成记录、商品素材和创作参考
   - 项目详情提供「继续创作」，空项目提供「开始创作」；恢复最近相关对话，无可恢复对话时创建绑定当前项目的空白会话，后续生成默认保存到当前项目
   - 项目图片点击后在弹窗预览并切换；「编辑」进入创作页，优先恢复图片来源对话并定位选中该图，直接使用最新编辑文档，下载与删除仍在项目详情完成
   - 项目卡片右上角操作菜单支持删除整个项目，详情页不提供删除整个项目入口；确认后物理删除数据库中的项目、项目内图片、编辑记录及关联的整段对话
   - 项目内图片与商品素材卡片悬浮显示删除入口；单图删除只删除该图片与编辑记录，保留项目、对话文字及其他图片
   - 删除项目内最后一张图片时，明确提示当前项目及关联对话会一起删除，确认后事务内执行；取消保留全部内容
   - 进行中的任务、其他作品引用及跨项目共享对话需先处理关联，删除失败不产生部分删除
7. 本地设置
   - Codex CLI 状态、当前模型目录与统一调用模型选择、本地目录和任务状态

## 核心流程

### Agent

```text
输入目标（素材可选）
→ 识别需求
→ 检查必要参数
→ 缺失信息时追问
→ 生成计划并补全参数
→ 调用本地工具
→ 检查结果
→ 局部重试或完成
→ 保存项目
```

创作页采用「集中补充缺失需求 → 自动整理参数并生成 → 同页画板结果」。首次可集中询问商品或参考素材、张数、风格及内容要求；用户可选择不提供素材或采用默认值，回复后不重复追问已说明的内容。纯文字生成的是视觉示意；有商品原图时沿用素材。需求明确后自动开始生成并消耗 Codex 账户额度，任务支持查看状态、停止和失败重试。项目未指定时自动创建，同会话后续执行默认沿用已有项目。对话内作品缩略图联动画板；选中作品可通过已有素材接口作为下轮原图，再明确修改和保留要求。

创作页基础编辑就近完成：生成整图固定为画布内容，不提供移动、缩放、隐藏、删除或额外底色；新增文字、图片图层、形状和画笔可继续变换、裁剪、显隐锁定、调整层序、复制删除及撤销重做，复用同一编辑文档自动保存。下载和下轮引用使用当前编辑画面；生成原图保留。

当前创作保留整图生成的视觉一致性，生图完成时保存整张图片，不直接获得模型的原生设计图层。用户新增文字、图片、形状时直接保留独立图层；原图内的文字和物体在编辑时按需识别、抠图或拆层。新套图和详情模块的程序排版标题、文案直接保存为独立文字层，原始生成图片保留；整套 ZIP 和详情长图包含最新保存的编辑内容。旧结果沿用已有编辑文档，不自动识字或重跑生成。

单张宣传图与封面由 AI 先整理文案、构图和配色，再一次生成完整图文；用户指定文案必须保留，需要文案但未提供时可主动创作场景、情绪与表达，不要求用户自行撰写；不得捏造未提供的品牌、价格、规格、认证等具体信息。无字商品图不主动添加营销文字。描述中的明确场景优先于默认背景。单张图检查失败后的自动重试携带具体检查意见，从原素材及原要求重新生成，最多一次；这不是局部改字，不保证其他区域像素不变。本轮修复限于已复现的单张图失败链路，套图与详情模块仍沿用现有排版流程。

自动创作完成后另生成平台发布文案，包含标题、备选标题、正文、标签、互动和行动引导；文案独立保存，失败可单独重试，不影响已保存的图片。自动流程在服务端维护状态，页面刷新不应重复触发生成；服务重启中断的任务需要手动重试。真实模型的端到端效果与防重复行为仍需验收。

商品图、套图、详情页与对话内方案提供创作方案保存、更新、预览应用和删除。方案保存现有参数快照，不保存商品原图；应用默认保留当前素材和商品事实，仅复用视觉参数与模块结构，恢复旧文案需明确选择并核对。品牌预设保存白名单字体、主色、文字色、背景色与统一风格描述；套图和详情生成保存独立品牌快照，预设更新或删除不会改变旧任务与重试参数。平台、地区、语言、商品名称、全部卖点与模块角色进入生成提示，不以已填写平台代替平台上架合规验收。

创作页要求全部非视频工具及交互对标。图片工具提供局部涂抹改图、消除、无痕改字、抠图、超清、扩图、识字编辑与拆层，使用独立任务记录；直接编辑文字、抠图和拆层点击入口即提交，其余工具完成选区或参数后点击执行。处理中可停止，失败可重试，成功产生同会话新作品。识字必须识别图片真实文字、重建底图并生成可编辑文字；无痕改字则重绘图片中的文字，不产生文字层。拆层按素材提取独立背景、透明商品、可见装饰及识别出的文字，不能恢复被遮挡的原内容。编辑范围包含多画板自由排布、绝对缩放、视口恢复、点击放置文字、拖动绘制形状、素材库、自有电商版式、文字格式、图片调色和 PNG/JPG 尺寸导出。逐项参考实测和真实效果仍属于完成目标，不能以按钮已存在缩小本次验收范围。各功能的模型/工具分工见 [创作工具契约](creation-tools-contract.md#功能与处理方式)，剩余验证见 [剩余事项](../handoff.md)。

### 商品图

```text
上传商品
→ 主体处理
→ 选择推荐场景、参考图或文字描述
→ 设置比例、数量和质量
→ 生成
→ 重试、编辑、保存或导出
```

### 商品套图与详情页

```text
上传商品素材
→ 设置平台、地区、语言和尺寸
→ 填写商品卖点
→ 选择套图结构或详情模块
→ 批量生成
→ 单图重试与编辑
→ 整套导出
```

## Agent 判定标准

系统必须具备目标理解、参数补全、任务规划、工具选择、结果观察和调整执行能力。仅将用户输入映射到一个固定接口，不视为完整 Agent。

## 本机邀请制试用

本机保持常开，通过 HTTPS 内网穿透供少量受邀用户使用；大模型继续使用本机登录的 Codex CLI，不改用 API Key。增加全局账号密码登录弹窗，参考美图设计室的左侧品牌展示、右侧表单结构，使用本项目自己的品牌和图片。管理员通过本机命令开通账号、重置密码或停用账号，不开放公众注册、短信验证码或第三方登录。

匿名用户可浏览首页和填写创作描述；访问创作工具、项目或提交上传时需要登录。登录成功继续原操作，关闭弹窗保留输入；登录失败在表单内显示错误。退出前保存当前作品和画板布局。项目、素材、对话、任务、下载和 SSE 按账号隔离；现有数据全部归首次创建的管理员。成员不能查看本机 CLI 和模型环境设置。

各账号共用本机额度，规划、生图和图片处理通过统一串行队列执行，沿用现有等待、取消和失败提示。本轮不包含个人每日额度、全局队列名次和自动磁盘清理。

## MVP 不包含

- 移动 App
- 云端多节点部署和完整商业化多租户 SaaS
- 团队实时协同
- 在线支付、发票和商业授权系统
- AI 模特、试衣、试鞋和完整视频生产
- PPT、Logo、办公设计和泛社媒设计
- 像素级复制第三方商标、品牌素材和受保护模板

## 验收标准

- 1440px PC 页面下主要布局和操作完整可用。
- 首页、商品图、商品套图和详情页流程能够走通。
- 任务包含等待、执行、成功、失败、取消和重试状态。
- 结果可保存到项目，并能进入编辑器继续处理。
- 页面刷新或服务重启后，已持久化任务和项目不丢失。
- Codex CLI 不可用、未登录或额度受限时提供明确错误。
- 模型提供者可替换，页面和业务流程不依赖 CLI 原始事件格式。
