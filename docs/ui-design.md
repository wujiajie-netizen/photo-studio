# UI 设计与页面规范

## 目标与取证

以美图设计室真实页面和交互作为结构参考，使用自有品牌、文案、图标和版式。按用户本次授权下载参考站图片用于首页灵感和空状态的风格示例，来源记录在 `apps/web/public/images/README.md`，不作为用户实际生成结果。1440px 桌面视口为主要验收基准，同时检查 1024px 下关键操作可见、页面无溢出。

依据优先级：真实页面与交互、官方帮助、已确认产品流程、自主设计补齐状态。不能从单张图片猜完整交互；参考来源、视口和状态见 [参考索引](references/designkit/index.md)。截图只作为内部参考。

## 页面结构

| 页面 | 布局与主操作 |
| --- | --- |
| 工作台首页 | 固定主导航，任务输入、常用电商工具和最近项目 |
| 创作会话 | 全屏自由画布，左侧悬浮对话与固定输入，画布上的文件操作、工具和缩放悬浮显示 |
| 商品图、套图、详情页 | 顶部任务栏、任务类型导航、配置栏和结果预览，配置独立滚动 |
| 项目与资产 | 项目、素材列表，搜索、预览及继续编辑 |
| 独立编辑器 | 顶部文件操作、工具栏、属性区与中央画布 |
| 本地设置 | Codex 状态、本地目录与任务状态，作为辅助入口 |

## 创作交互

- 对话按轮次展示需求、回复、方案、执行状态和结果缩略图。方案紧跟本轮回复，素材可选，参数按需展开，点击“开始生成”后执行；未指定项目时自动创建，同会话后续复用项目。
- 输入区固定底部，消息独立滚动；Enter 发送、Shift+Enter 换行，中文组合输入不触发发送。阅读旧消息时不强制跳到底部，历史通过菜单搜索和切换。
- 缩略图联动画板，选中作品可引用当前编辑画面继续创作；未知商品规格、功效、成分、产地和认证不能由助手补造。
- 创作页画布覆盖整个窗口，对话面板在桌面视口宽 390px、距左侧及上下边缘 10px，1024px 下缩为 320px。适应画板避开对话与属性面板，手动平移仍可经过面板后方。新生成结果由本轮可见缩略图移动放大到画板；历史会话恢复不重播，点击缩略图可重新定位，减少动态效果时直接显示。
- 多画板使用真实编辑文档，标题拖动排布。普通滚轮与抓手平移，空格临时抓手，Ctrl+滚轮以指针缩放；绝对缩放 3%–300%，分别提供适应当前和查看全部，恢复布局、视口和选择。
- 浮动操作条随选中图片或文字显示，并保持可见；属性面板按需展开。选择、抓手、文字、画笔、形状与素材库互斥。
- 文字点击放置、双击编辑，提供字体、字号、单色或两端线性渐变、角度、格式、对齐、字距和行高。形状拖动绘制，线条与箭头方向跟随拖动。
- “编辑文字”菜单中的“直接编辑”识别原图并创建独立文字层；“无痕改字”需要涂抹原字并输入新内容，输出仍是图片文字；“添加文字”直接新增文字层。直接编辑、抠图和拆层点击入口即提交，其他图片工具完成选区或参数后执行。
- 素材库提供模板、素材、图片页签及搜索分类，只使用自有电商版式、基础图形和用户素材，插入与应用可撤销。
- 裁剪、扩图和涂抹使用独立暂存状态，取消保留原文档；设置选区、参数及提交请求期间不切换作品。后台任务与原作品绑定，当前实现提交后可切换画板，任务排队或运行期间禁用新图片工具入口，支持停止与失败重试。图片工具参数及任务反馈见 [接口契约](creation-tools-contract.md)。
- 同页与独立编辑器共享文档和自动保存。切换作品或离开前保存，失败保留内容并阻止离开；版本冲突提示，刷新恢复已保存数据。
- 下载提供文件名、PNG/JPG 和原尺寸/2 倍/4 倍，包含当前编辑；PNG 保留透明背景，JPG 白底并提供 100/80/70/50/20% 压缩质量。输出最长边 8192、总计 3200 万像素以内，尺寸倍率、压缩质量与 AI 超清分别处理。

## 视觉与状态

采用统一的圆角、边框、阴影、间距、色彩和图标体系。主操作突出，辅助信息弱化；表单、素材和结果层级清晰，属性围绕当前选择显示，不放置不可用的功能按钮。

创作会话保持现有布局，字体优先使用本机 Noto Sans SC，其他系统依次使用苹方、微软雅黑 UI 与系统无衬线字体。正文与输入使用 14px，方案说明与工具标题使用 13–14px，辅助信息使用 12px；正文采用常规字重，标题与操作使用 500–600。中性灰区分文本层级，柔和紫色标记操作和选中状态，边框与阴影保持轻量，图标线宽统一；字体调整不改变面板宽度、定位与工具栏排布。

工作台采用浅色背景与紫色创作强调色，首页使用柔和渐变、悬浮作品、大幅灵感图片和分类筛选。点击灵感只填入可编辑描述并聚焦输入框，发送与确认生成沿用既有流程。商品制作页空状态中的图片明确标注风格参考；项目、表单和编辑区沿用统一视觉变量。动效包含轻微悬浮、卡片悬停和页面淡入，并尊重系统减少动态效果设置。

核心页面覆盖空状态、加载、输入错误、排队、运行、取消、成功、部分失败、重试、已保存，以及 CLI 或本地工具不可用。异步反馈就近显示，用户能辨认当前任务和下一步操作。

页面按结构、视觉、交互、数据接入的顺序推进；验收检查关键操作位置、文本层级、视觉一致性、各类状态以及入口至保存的连续流程。参考实测中仍缺失的状态见 [剩余事项](../handoff.md)；产品范围或工作流发生冲突时先确认。
