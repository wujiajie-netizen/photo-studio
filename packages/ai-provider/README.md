# 模型提供者

统一 `AgentModelProvider` 包含 `run`、`continue`、`generateImage` 与 `cancel`。文本事件覆盖启动、内容增量、工具调用、完成、失败和取消。`CodexCliProvider` 归一化 CLI JSONL 与应用协议，业务和页面不解析原始事件。

规划和文案采用 `codex exec`、只读沙箱及独立任务目录，禁用所有工具。生图采用 `codex app-server --stdio`，仅允许原生图片生成，关闭 Shell、插件、MCP、浏览器、应用及子 Agent。真实 `imageGeneration` 完成事件中的 PNG 字节经校验后返回；无图片、未知工具、超时、取消、额度和登录错误均不能记为成功。

应用协议初始化后读取提供者生图能力，并仅获取 MCP 名称用于关闭工具，不保存配置响应或凭据。生图会话为临时会话，任务输入、经过删减的事件记录及诊断日志保存在本地数据目录。Codex 自身也可能将生图副本保存到其生成图片目录；应用不读取这个路径。

安装与 ChatGPT 登录检测不调用模型。真实任务支持 JSON Schema、指定会话恢复、取消、180 秒超时以及输出大小限制；输入、Schema 和日志仅写入运行目录。已通过本机 CLI 0.139.0 实际验证结构化结果和会话恢复。
