## 已确认的 Agent 结构

- 会话：`id`、`title`、`createdAt`、`updatedAt`。标题由首条需求的前 80 个字符生成。
- 消息：`id`、`sessionId`、`role`（`user` / `assistant`）、`content`、`createdAt`。
- 任务：`id`、`sessionId`、`status`（`queued` / `running` / `succeeded` / `failed` / `cancelled`）、`createdAt`、`updatedAt`、`error`（字符串或 `null`）。
- 结果：`summary`、`questions`（字符串数组）、`plan`（步骤数组）。每步包含 `title`、`description`、`tool`；工具仅为 `product-image`、`product-kit`、`detail-page` 或 `null`。
- 用户需求必填，最多 2000 个字符；结果使用 JSON Schema 和业务校验双重检查，拒绝未知字段和未知工具。
- SQLite 保存会话、消息和任务；CLI 会话编号只在后端的 `provider_session_id` 列保存，不进入公开会话类型。
- 已验证结果保存在任务运行目录的 `result.json`，通过独立结果接口读取；消息 `content` 保存用户文本或助手摘要。
- 任务先持久化再推送 SSE；重连发送当前任务快照。服务重启后，未完成任务保留并标记失败，用户手动重试。

### 新增接口与已确认结构

`CommerceTask` 保存 `id/kind/parameters/status/progress/items/createdAt/updatedAt/error`，每项保存 `id/index/title/status/error/resultId`。参数包含素材、主体、场景、比例、质量、商品名称、平台、地区、语言、卖点及模块；模块仅使用 `type/title/content`，规格与对比必须填写用户事实。

`EditorDocument` 保存 `id/resultId/projectId/name/width/height/background/layers/revision/createdAt/updatedAt`；图层使用用户确认的图片或文字属性，数组顺序表示叠放顺序。`AgentExecution` 保存 `id/sessionId/planTaskId/projectId/status/progress/steps/createdAt/updatedAt/error`，步骤保存 `id/title/tool/parameters/taskId/status/observation/retryCount`。

| 接口 | 用途 |
| --- | --- |
| `POST /api/commerce/tasks/:kind` | 创建商品套图或详情任务 |
| `GET /api/commerce/tasks?kind=...` | 历史任务 |
| `POST /api/commerce/assist` | Codex 辅助整理卖点与模块文案 |
| `GET /api/commerce/tasks/:id/events` | 模块任务 SSE |
| `POST /api/commerce/tasks/:id/retry` | 仅重试失败模块 |
| `POST /api/commerce/tasks/:id/items/:itemId/retry` | 单模块重新生成 |
| `GET /api/commerce/tasks/:id/export?format=zip\|long` | ZIP 或详情长图 |
| `POST /api/editor/documents` | 按生成结果打开作品 |
| `GET/PATCH /api/editor/documents/:id` | 读取、按 revision 保存作品 |
| `GET /api/agent/tasks/:id/executions` | 计划的执行历史 |
| `POST /api/agent/executions` | 确认参数后执行 |
| `GET /api/agent/executions/:id/events` | 执行 SSE |
| `POST /api/agent/executions/:id/cancel` | 取消执行 |
| `POST /api/agent/executions/:id/retry` | 重试未完成步骤 |
| `GET /api/image-engine/status` | Codex 图片入口状态 |
